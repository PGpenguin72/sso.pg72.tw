# PGID 服務條款

**生效日期:** 待定(公開上線時填入)
**最後更新:** 2026-07-16

歡迎使用 PGID(以下稱「本服務」),由 PG72(以下稱「我們」)提供,網址為 `https://sso.pg72.tw`。PGID 是 PG72 自建的身分認證服務(Identity Provider),讓你以單一身分登入 PG72 旗下與已授權的第三方應用程式。

使用本服務即表示你同意本條款。若你不同意,請勿使用本服務。

## 1. 服務內容

本服務提供:

- 以 Google、Passkey(無密碼)以及其他支援的社群帳號(如 Discord、GitHub、Facebook、Apple、Telegram)登入;
- 以 OAuth 2.1 / OpenID Connect 授權第三方應用程式存取你的基本身分資訊;
- 帳號中心:管理個人資料、登入方式、已授權應用程式、裝置工作階段(session)與安全活動記錄。

本服務**不儲存你的密碼**;登入以 OAuth 提供者與 Passkey 憑證為準。

## 2. 帳號資格與註冊

- 本服務初期採**邀請制**,未來可能開放公開註冊。
- 你必須提供正確資訊,並就你帳號下的一切活動負責。
- 你必須妥善保管你的登入方式(Passkey 裝置、社群帳號)。若懷疑帳號遭盜用,請立即透過第 10 條的聯絡方式通知我們。
- 我們保留於你違反本條款、或為保護服務與其他使用者安全時,**停權或終止**帳號的權利。

## 3. 可接受使用

你同意不會:

- 未經授權存取他人帳號或資料;
- 干擾、破壞、逆向或試圖繞過本服務的安全機制;
- 以自動化方式濫用註冊、登入或授權端點;
- 冒充他人或 PG72,或以誤導方式註冊 OAuth 應用程式(例如以近似官方的名稱誘導使用者授權);
- 將本服務用於任何違法用途。

我們提供 OAuth 應用程式的**檢舉**機制;若你認為某應用程式不受信任或濫用授權,可於帳號中心檢舉,我們會審查並得停用該應用。

## 4. 第三方登入與應用程式

- 你透過第三方(如 Google)登入時,亦受該第三方之條款約束。
- 你可授權第三方應用程式存取你的基本身分(依你於同意畫面核可的範圍)。你可隨時於帳號中心撤銷授權。
- 對於第三方應用程式如何使用你的資料,我們不負責;請於授權前檢視該應用的開發者、導向網域與請求權限。

## 5. 你的內容與資料

你對本服務的資料處理,適用我們的[隱私權政策](/pp)。使用本服務即表示你亦同意該政策。

## 6. 服務可用性與變更

- 本服務目前處於早期階段,可能不定時維護、變更或中斷,恕不另行個別通知。
- 我們可能新增、修改或移除功能。重大變更會盡合理努力公告。

## 7. 免責聲明

本服務按「現狀」與「現有」提供,不就可用性、無誤、安全性或適合特定用途作任何明示或默示保證。你理解自建身分服務仍在演進中,並自行承擔使用風險。

## 8. 責任限制

在法律允許的最大範圍內,對於因使用或無法使用本服務所生之任何間接、附帶、衍生性損害,我們不負賠償責任。

## 9. 條款修改

我們可能不時修訂本條款。修訂後將更新本頁「最後更新」日期;重大變更會另行公告。於變更生效後繼續使用本服務,即視為接受修訂後條款。
